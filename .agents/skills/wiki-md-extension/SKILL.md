# wiki-md-extension

## Runtime pieces

| Context | Source | Built? |
|---|---|---|
| Content script | `src/islands/*.js` → `extension/content.js` | yes, `npm run build` |
| Popup | `extension/popup/{html,css,js}` + `lib/converter.bundle.js` | popup files hand-written |
| Options | `extension/options/` | hand-written |
| Background | `extension/background.js` | hand-written |

Never edit `extension/content.js` or `extension/lib/*.js`; they are regenerated and tracked in git.

All code uses `browser.*` (webextension-polyfill on Chrome). Log prefix: `[Wiki↔MD]`.

## Messages

Message `type` strings are the contract. Renaming one means updating every sender and handler.

- Popup/background → content (`browser.tabs.sendMessage`): `getPageInfo`, `extractPageContent`, `exportSingleHtml`, `insertMarkdownToJira`, `collectAttachments`, `convertAndCopy`, `insertFromClipboard`.
- Popup/content → background (`browser.runtime.sendMessage`): `fetchImagesAsBase64`, `downloadToFolder`, `downloadAttachments`. Cross-origin image fetch must happen in background (host permissions), not the content script.

Find the handler: `rg -n "'<type>'" src/islands extension/background.js extension/popup/popup.js`.

## Adding content-script behavior

- New island file `src/islands/<name>.js` exporting `init<Name>Island()` that calls `registerHandler(type, fn)` from `message-bus.js`; call it in `src/islands/index.js`.
- Islands import only `message-bus.js` and `notification.js`, never each other.
- The content script has no Turndown. Heavy conversion belongs in the popup via `JiraMdConverter`.

## Settings

`browser.storage.local` key `wikiMdSettings`. Defaults are duplicated: `DEFAULTS` in `extension/options/options.js` and `SETTING_DEFAULTS` in `extension/popup/popup.js`. A new setting goes in both, plus the options HTML.

## Manifest and Chrome

`extension/manifest.json` is the Firefox manifest (`menus`, `background.scripts`, gecko id). The Chrome manifest is generated by two copies of the same transform: `build.js` (`generateChromeManifest`) and `scripts/package-chrome.js`. Change both if the transform changes. Content scripts only match `*.atlassian.net` and `*.jira.com`; other hosts rely on `optional_host_permissions`.

## Load and check

```bash
npm run build && npm run lint
npm run start:firefox        # web-ext run with the extension loaded
```

- Firefox manual: `about:debugging#/runtime/this-firefox` → Load Temporary Add-on → `extension/manifest.json`.
- Chrome: `npm run package:chrome`, then Load unpacked → `dist/chrome/`.
- Content-script changes need a page reload; background changes need an extension reload.
- For automated checks, the Firefox DevTools MCP (`install_extension`, `list_console_messages`) can load `extension/` and read `[Wiki↔MD]` logs. Real behavior needs a logged-in Confluence/Jira page.
